# 05 数字信号、逻辑电平、ADC 与 PWM

**一句话**：数字世界只有高低电平；ADC 把模拟变数字，PWM 把数字变「伪模拟」。

## 1. 逻辑电平

| 家族 | 高电平 | 低电平 | 注意 |
|---|---|---|---|
| 3.3V CMOS (ESP32) | ≥2.6V 认高，≤0.8V 认低 | | 输入耐压 ~3.6V |
| 5V TTL/CMOS | ≥2.0V 认高 | ≤0.8V | 5V 输出进 3.3V 脚需分压 |
| 开漏/开集 | 需外部上拉 | | I2C 就是开漏 |

- **上拉/下拉**：给引脚确定默认态；按键常用 10k 上拉 + 按下接地。
- **悬空引脚**：高阻态会乱跳、还可能增加功耗 → 一定要拉。
- ESP32 内部上下拉约 45k，多数场景够用；总线/长线建议外部 4.7~10k。

## 2. ADC 模数转换

- ESP32：12 位（0~4095），衰减档决定量程；**ADC1 可与 WiFi 共存，ADC2 不行**。
- 误差来源：非线性（低端/高端差）、噪声、源阻抗、电源纹波。
- 提精度四招：
  1. 多次采样取中位数/平均（16~64 次）。
  2. 输入并 100nF、串 1k 或更低源阻抗。
  3. 用 3.3V 稳定电源做基准（或外部基准）。
  4. 校准：两点校准（0V 与已知电压）存 NVS。

`电压 = 读数/4095 × 量程`；测高于量程的电压先分压。

## 3. DAC 与 PWM

- ESP32 真 DAC：GPIO25/26，8 位，适合音频/简单波形。
- **PWM（LEDC）**：改变占空比；配 RC 低通可得到平滑模拟电压；驱动 LED 亮度、舵机、电机速度。
  - LED：1~5kHz，占空比 0~100%。
  - 舵机：50Hz，脉宽 0.5~2.5ms。
  - 电机：10~20kHz 避开可听噪声。

## 4. 中断与定时

- 边沿触发中断：按键、脉冲计数（编码器/流量计）。
- 硬件定时器/PCNT：不占 CPU 的精确计数。
- 消抖：硬件 RC 或软件 20ms 延时/状态机。

## 5. 常见坑

1. 5V 信号直进 GPIO → 损坏；用分压/电平转换/光耦。
2. ADC2 与 WiFi 同时用 → 读数全 0 或乱跳。
3. PWM 频率太低 LED 闪烁、电机啸叫；太高开关损耗大。
4. 开漏总线忘上拉 → 永远读低/读不到 ACK。
5. 用 delay() 做精确时序 → 被 WiFi/中断打断；用 hardware timer 或 micros()。

## 6. 动手验证

1. 电位器中点接 GPIO34，串口打印 ADC 值与换算电压；转动观察。
2. LEDC 1kHz 输出 0/25/50/75/100% 占空比，观察亮度；加 10k+10µF 低通后测平均电压是否≈占空比×3.3V。
