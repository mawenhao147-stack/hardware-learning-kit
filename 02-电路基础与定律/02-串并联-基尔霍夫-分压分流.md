# 02 串并联、基尔霍夫定律、分压与分流

**一句话**：串联分压、并联分流；节点电流守恒（KCL）、回路电压守恒（KVL）。

## 1. 串联与并联

| | 串联 | 并联 |
|---|---|---|
| 电流 | 处处相等 | 按电导分配 |
| 电压 | 按阻值分配 | 处处相等 |
| 总阻值 | R1+R2+… | 1/(1/R1+1/R2+…) |
| 直觉 | 水管变长 | 水管变粗 |

速算：两只相同电阻并联 = 一半；10k∥10k=5k；1k∥10k≈909Ω（接近小的那个）。

## 2. 基尔霍夫定律

- **KCL**：流入节点的电流之和 = 流出之和。
- **KVL**：沿任一闭合回路，电压升 = 电压降。

**例题**：节点 A 接 3.3V 经 10k，接 GND 经 10k，接 ADC（不取电流）。
KVL：3.3 = I×10k + I×10k → I=0.165mA → V_A = 1.65V。

## 3. 分压电路（ADC 采样必备）

![分压](../figures/voltage-divider.png)

`Vout = Vin × R2 / (R1+R2)`

设计步骤：
1. 确定被测最大值 Vin_max 与 ADC 量程（ESP32 建议 ≤3.1V）。
2. 选比例：R2/(R1+R2) = 3.1/Vin_max。
3. 选绝对值：总阻 10k~100k（太小耗电、太大受 ADC 采样电容影响）。
4. 并 100nF 电容稳定采样、滤噪声。

**负载效应**：若 Vout 接了会取电流的负载，负载与 R2 并联，分压比失真 → 后级加电压跟随器（运放）。

## 4. 分流电路

电流表扩程、LED 恒流近似、采样电阻都是分流/串采样思想。
`I1 = Itotal × R2/(R1+R2)`（两支路并联时）。

## 5. 常见坑

1. 分压电阻精度决定测量精度：用 ±1% 或 ±0.1%。
2. 忘记 ADC 输入阻抗限制：源阻抗 >100k 时读数偏低且漂移。
3. 并联电容过大：信号变化慢（RC 变大），测快速变化量会滞后。
4. 用分压给大电流负载供电：效率极低且不稳，请用稳压器。

## 6. 动手验证

1. 搭 10k+10k 分压接 3.3V，实测中点电压≈1.65V。
2. 在中点再接一只 10k 到地，重测（应≈1.1V），体会负载效应。
3. 用工具箱.html 的分压计算器反推电阻组合。
