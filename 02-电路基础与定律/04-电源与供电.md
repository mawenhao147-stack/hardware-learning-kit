# 04 电源与供电：LDO、DC-DC 与电池

**一句话**：电源是电路的心脏；选错电源，后面一切调试都是徒劳。

## 1. 三类稳压方案

| 方案 | 原理 | 效率 | 纹波 | 典型芯片 | 适用 |
|---|---|---|---|---|---|
| LDO | 线性放大，压差变热 | (Vout/Vin) | 极低 | AMS1117-3.3、ME6217、HT7533 | 压差小、电流小、射频前端 |
| Buck 降压 | 开关+电感储能 | 85~95% | 中（mV 级） | MP1584、TPS5430、SY8089 | 压差大、电流大 |
| Boost 升压 | 开关升压 | 85~95% | 中 | MT3608、SX1308 | 电池升 5V/12V |

**LDO 发热**：P = (Vin−Vout)×I。5V→3.3V @300mA = 0.51W，SOT-23 封装会烫；12V→3.3V @300mA = 2.6W，必须换 Buck。

## 2. ESP32 供电要点

- 模组要求 3.3V ±0.3V，**发射瞬间峰值电流 >300mA**。
- 开发板：USB 5V → 板载 LDO → 3.3V；用 **5V/2A 以上** 的 USB 电源或电脑口（部分电脑口仅 500mA 会 brownout 复位）。
- 自己画板：LDO 选 ≥500mA 低压差（ME6217/RT9013），输入输出各 10~22µF + 100nF。
- 电池方案：锂电 3.7V → LDO（压差够）或 Buck-Boost；加 TP4056 充电 + DW01 保护。

## 3. 电源树设计法

从负载往回推：
```
负载清单 → 各路电压/电流 → 选拓扑 → 算效率与发热 → 选器件 → 加保护(反接/过流/TVS)
```
例：ESP32(3.3V/240mA峰) + 传感器(3.3V/5mA) + 继电器(5V/70mA) + 灯带(5V/300mA)
→ 5V 主轨 Buck(12V→5V/1A)；3.3V 由 5V 经 LDO(500mA)；继电器/灯带直接 5V。

## 4. 电池与续航

- 锂电 3.7V 标称：满 4.2V、空 3.0~3.3V；**必须带保护板**。
- 容量 mAh × 3.7V / 1000 = Wh；续航 ≈ 容量 / 平均电流。
- 降低平均电流的三板斧：深度睡眠、降低发射功率/占空比、关掉常耗电外设（分压电阻、上拉、LED）。

## 5. 常见坑

1. **USB 口供电不足** → WiFi 一连就复位（brownout）。
2. **LDO 压差不够**：AMS1117 压差约 1.1~1.3V，3.7V 锂电放到 3.5V 时输出不足 3.3V → 选低压差 LDO。
3. **开关噪声进 ADC/射频**：Buck 输出加 LC/磁珠滤波，布局环路要小。
4. **共地不良**：多电源系统所有 GND 必须连在一起。
5. **热插拔浪涌**：长导线+大电容上电瞬间电流冲击 → 加限流/预充或 TVS。

## 6. 动手验证

1. 测开发板 3V3 在 WiFi 扫描时的最低电压（万用表 min 档或示波器），应 >3.0V。
2. 摸 AMS1117 温度，体会 P=(Vin−Vout)×I。
