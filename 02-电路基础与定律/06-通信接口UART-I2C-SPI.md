# 06 通信接口：UART / I2C / SPI

**一句话**：设备之间说话的方式；UART 最简单、I2C 最省线、SPI 最快。

![时序](../figures/bus-timing.png)

## 1. 三者对比

| | UART | I2C | SPI |
|---|---|---|---|
| 线数 | 2 (TX/RX) | 2 (SDA/SCL) | 4 (SCK/MOSI/MISO/CS) |
| 速率 | 1.2k~4M | 100k~3.4M | 10~80M |
| 多设备 | 点对点 | 地址寻址(127) | 每设备一根 CS |
| 时钟 | 异步(约定波特率) | 同步 | 同步 |
| 电平 | 推挽 | 开漏+上拉 | 推挽 |
| 典型 | GPS、蓝牙、串口屏 | OLED、IMU、EEPROM | SD 卡、TFT、Flash |

## 2. UART 要点

- 交叉接线：A-TX → B-RX；**共地**。
- 参数四要素：波特率、数据位、停止位、校验（常用 115200 8N1）。
- ESP32 有三组 UART；UART0 默认串口日志+烧录。
- 长线/干扰环境：加串阻 22~100Ω、或用 RS-485 差分收发器。

## 3. I2C 要点

- 开漏 + 上拉（4.7k 常用；线长/设备多降到 2.2k）。
- 地址 7 位；冲突时换地址脚或加 I2C 多路器。
- ESP32 默认 SDA=21、SCL=22，可任意重映射。
- 排错神器：i2cscan 例程列出所有在线地址；逻辑分析仪看 ACK。

## 4. SPI 要点

- 四种模式（CPOL/CPHA）要与器件手册一致。
- CS 片选：低有效，一次只拉低一个。
- 速率从低往高试；线长 >20cm 建议降速或加串阻。
- MISO 是开漏/三态的器件可共享总线。

## 5. 其他常见接口

| 接口 | 线数 | 用途 |
|---|---|---|
| 1-Wire | 1 | DS18B20 温度 |
| CAN | 2(差分) | 汽车/工业，需收发器 |
| USB | 2(差分) | 烧录/供电/HID |
| 单线时序(WS2812) | 1 | 灯带，时序严格 |
| RS-485 | 2(差分) | 百米级总线 |

## 6. 常见坑

1. 波特率不一致 → 乱码。
2. I2C 上拉缺失/过强 → 波形边沿异常、ACK 丢失。
3. SPI 模式错 → 读全 FF 或 00。
4. 忘记共地 → 一切皆乱。
5. 热插拔 I2C/SPI → 闩锁风险，先断电。

## 7. 动手验证

1. 两块 ESP32 互发 UART 字符串。
2. i2cscan 扫 OLED，再点亮显示文字。
3. SPI 读 SD 卡文件列表（或 SPI TFT 画线）。
