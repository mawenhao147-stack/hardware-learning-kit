# 01 电压、电流、电阻与欧姆定律

**一句话**：电压是「推」，电流是「流」，电阻是「拦」；三者关系 `U = I × R`。

## 1. 水流类比

| 电学 | 水路 | 单位 |
|---|---|---|
| 电压 U | 水压/水位差 | 伏特 V |
| 电流 I | 水流量 | 安培 A（mA=千分之一） |
| 电阻 R | 管道粗细/阀门 | 欧姆 Ω |
| 功率 P | 水流做的功 | 瓦特 W |

- 电压是**两点之间**的电位差，永远说「A 点相对 B 点几伏」。
- 电流是电荷的流动，**串联路径上处处相等**。
- 地 GND 是我们人为规定的 0V 参考点，不是「电的终点」。

## 2. 欧姆定律与功率

```
U = I × R      I = U / R      R = U / I
P = U × I = I² × R = U² / R
```

**例题**：3.3V 电源经 330Ω 电阻点亮红 LED（Vf=2.0V）。
- 电阻两端电压 = 3.3 − 2.0 = 1.3V
- 电流 I = 1.3 / 330 ≈ 3.9mA
- 电阻功耗 P = 1.3 × 0.0039 ≈ 5mW（1/16W 足够）

## 3. 数量级直觉

| 量级 | 例子 |
|---|---|
| 1µA | ESP32 深度睡眠、漏电 |
| 1mA | 指示 LED、上拉电阻电流 |
| 20mA | GPIO 单脚上限（建议 ≤12mA）、亮 LED |
| 100mA | 继电器线圈、ESP32 平均工作 |
| 300~500mA | ESP32 WiFi 发射峰值、舵机堵转 |
| 1~5A | 电机、灯带满亮 |

## 4. 测量三件套

![万用表](../figures/multimeter.png)

- 电压：**并联**，带电测。
- 电流：**串联**进回路（或测采样电阻压降换算）。
- 电阻/通断：**断电**测。

## 5. 常见误区

1. 「电流从正极流出被用掉」→ 电流在回路中守恒，被「用掉」的是能量。
2. 「GND 就是 0V 绝对值」→ 只是参考点；两个系统不共地，信号就没有回路。
3. 「电压高就危险」→ 危险取决于能否驱动足够电流通过人体；但高压更易击穿绝缘。
4. 忽略导线/接触电阻：大电流下 0.1Ω 接触电阻也会产生压降与发热。

## 6. 动手验证

1. 3.3V + 1kΩ + LED：分别测电阻压降、LED 压降，验证两者之和≈3.3V（基尔霍夫电压定律的雏形）。
2. 换 330Ω/1kΩ/10kΩ，观察亮度与实测电流，体会 `I=U/R`。
