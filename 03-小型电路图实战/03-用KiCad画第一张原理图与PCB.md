# 03 用 KiCad 画第一张原理图与 PCB

**一句话**：把面包板上的电路「固化」成板子：原理图 → 网络表 → 布局 → 布线 → 打样。

## 1. 工具与流程

- KiCad（免费开源，中文界面）：原理图 Eeschema + PCB Pcbnew + 3D 预览。
- 流程：建工程 → 画原理图(含 ERC) → 关联封装 → 导入 PCB → 布局 → 布线(DRC) → 出 Gerber → 打样 → 焊接 → 测试。

## 2. 原理图规范（让未来的你看得懂）

1. 电源符号统一：VCC/3V3/5V/GND 用标准符号，不要拉线满天飞。
2. 按功能分块摆放，信号左进右出。
3. 每个 IC 电源脚放 100nF 去耦，**画在原理图上**。
4. 关键网络命名：SDA/SCL/MOSI… 便于检查。
5. 跑 ERC：未连接引脚、单端网络、电源冲突都要处理。

## 3. 封装与器件库

- 优先用厂家提供的封装/3D 模型（立创商城/LCSC 编号可直接搜）。
- 电阻电容 0805 手焊友好；IC 选 SOP/SOIC 而非 QFN 入门。
- 建 BOM：位号、型号、封装、LCSC/贸泽编号、数量。

## 4. PCB 布局布线入门规则

| 项目 | 规则 |
|---|---|
| 板厚/层数 | 入门 2 层 1.6mm |
| 电源走线 | ≥0.5mm(20mil)，大电流加宽或铺铜 |
| 信号走线 | 0.2~0.25mm 足够 |
| 去耦电容 | 紧贴 IC 电源脚，先电容后 IC |
| 地 | 2 层板底层尽量完整铺地 |
| 晶振/天线 | 下方不走的信号、包地、远离接口 |
| 过孔 | 电源过孔多打几个；信号 0.3mm 孔 |
| 丝印 | 位号、极性、接口名称、版本号 |

## 5. 打样与焊接

- 出 Gerber + 钻孔 + 拾取文件 → 打样厂（5 片约 ¥10~30）。
- 贴片可选 SMT 贴片服务；手焊准备焊台、锡膏/锡丝、镊子、放大镜。
- 回板检查：通断（电源对地不短路）→ 上电（限流电源或串电阻）→ 测各路电压 → 烧录测试。

## 6. 第一个板子建议做什么

「ESP32 最小系统 + OLED + DHT22 + 一个按键 + 一个 LED」传感器节点：
- 用模组（WROOM-32）而非裸芯片，省射频与认证。
- 留出所有未用 GPIO 的排针，方便后续玩。
- 加电池座 + TP4056 充电，直接变成可穿戴原型。

## 7. 常见新手错误

1. 封装画错（引脚顺序/间距）→ 打样前用 3D 预览 +  datasheet 核对。
2. 电源与地网络没连全 → DRC 报 unconnected。
3. 去耦电容画了但布局离 IC 远 → 等于没画。
4. 丝印被焊盘/元件压住 → 装配看不清。
5. 没留测试点 → 调试抓瞎。
