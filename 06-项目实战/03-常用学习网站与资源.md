# 03 常用学习网站与资源（含介绍与适用阶段）

> 按「先看什么 → 再练什么 → 遇到坑查什么」整理；★ 为强烈推荐。

## 一、官方文档（权威、免费）

| 网站 | 介绍 | 适用 |
|---|---|---|
| ★ [Espressif 文档](https://docs.espressif.com/projects/esp-idf/zh_CN/latest/esp32/) | ESP-IDF 中文官方文档：API、功耗、射频、设计指南 | 第 4 阶段起 |
| ★ [ESP32 数据手册/硬件设计指南](https://www.espressif.com/zh-hans/products/socs/esp32) | 引脚、电气参数、PCB 设计准则（天线/电源） | 画板前必读 |
| [Arduino ESP32 核心](https://docs.espressif.com/projects/arduino-esp32/) | Arduino 框架下的 ESP32 API 与示例 | 入门写代码 |
| [KiCad 官方手册](https://docs.kicad.org/) | 原理图/PCB 操作手册，中文可切换 | 第 3/6 阶段 |

## 四、在线仿真与工具（不用买元件先验证）

| 网站 | 介绍 | 适用 |
|---|---|---|
| ★ [Wokwi (wokwi.com)](https://wokwi.com) | 浏览器里仿真 ESP32/Arduino：写代码直接跑，支持 OLED/DHT/WS2812 | 没板子时练代码 |
| ★ [Falstad 电路仿真 (falstad.com/circuit)](https://www.falstad.com/circuit/) | 交直流电路动态波形可视化，理解 RC/滤波/三极管神器 | 第 2 阶段 |
| [TinkerCAD Circuits](https://www.tinkercad.com/circuits) | 拖拽面包板+Arduino 仿真，新手友好 | 第 1~3 阶段 |
| [LCSC / 立创商城](https://www.lcsc.com) | 元件选型+datasheet+库存价格一站式 | 买元件 |
| [Octopart / AllDatasheet](https://www.alldatasheet.com) | 跨厂商搜数据手册 | 查手册 |
| [JLCPCB / 嘉立创](https://jlcpcb.com) | 打样+SMT 贴片下单 | 第 6 阶段 |

## 五、使用建议

1. **入门期**：SparkFun/Electronics Tutorials 建概念 + Falstad 看波形 + 本资料动手。
2. **ESP32 期**：Random Nerd Tutorials 跟做 → 官方文档查 API → Wokwi 无板练习。
3. **画板期**：立创开源广场找 3 个同类工程对比 → 读 Espressif 硬件设计指南 → 打样。
4. 查任何芯片：先 datasheet 的 **Pin Description** 与 **Electrical Characteristics** 两节，再搜应用笔记 (AN/APP Note)。
