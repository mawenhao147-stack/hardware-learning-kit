电阻色环计算器

选择色环 → 得阻值；或输入阻值 → 得五环颜色。

反向：输入阻值求五环

欧姆定律 / 功率

任填两个量，自动求其余。U=I·R，P=U·I。

LED 限流电阻

R = (Vcc − Vf) / If，并给出功耗与推荐标称值。

分压电路

Vout = Vin × R2 / (R1+R2)；也可由目标 Vout 反推比例。

RC 时间常数 / 截止频率

τ = R·C；fc = 1/(2πRC)。

电池续航估算

平均电流 = (唤醒秒×工作mA + 睡眠秒×睡眠µA/1000) / 周期秒。

ESP32 引脚查询

输入 GPIO 号或关键词（如 i2c、adc、flash）筛选。
