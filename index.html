VCC · 正电源（常见 5V / 3.3V）

1/4

① 基本信息

丝印VCC
英文全称Voltage Common Collector
中文含义正电源（常见 5V / 3.3V）
类别电源
电气特性电源输入脚，注意模块标 3V3 还是 5V

② 常见别名 / 板间差异

  • +5V
  • +3V3
  • V+
  • PWR
  • VIN(部分模块)
不同厂家丝印可能不同：以数据手册 Pin Description 为准；本资料收录常见变体。

③ 使用场景与典型接法

  • 给模块/芯片供电
  • 面包板电源轨红轨
  • 万用表红笔参考

④ ESP32 对应与易混注意

ESP32：ESP32 开发板 3V3 脚对外供电能力约 500mA（视 LDO）

⚠ 把 5V 模块接 3V3 会不工作；把 3V3 模块接 5V 会烧

01 电阻 Resistor

一句话：电阻限制电流、分配电压，是电路里数量最多的元件。

1. 它做什么

  • 限流：保护 LED、限制三极管基极电流。I = U / R
  • 分压：两只电阻串联，把高电压按比例降低（见 分压电路）。
  • 上拉/下拉：给引脚一个确定的默认电平（ESP32 内部已有，外部常加 10k）。
  • 采样：小阻值（0.1Ω）把电流变成电压供 ADC 测量。
  • 匹配/阻尼：串口串 22~100Ω 抑制振铃；LED 数据线串 330Ω。

3. 读色环与贴片丝印

  • 4 环：2 位有效数字 + 倍率 + 误差。例：棕黑红金 = 1 0 ×100 = 1kΩ ±5%
  • 5 环：3 位有效数字 + 倍率 + 误差。例：棕黑黑红棕 = 100 ×100 = 10kΩ ±1%
  • 贴片丝印：103=10k、472=4.7k、4R7=4.7Ω、R100=0.1Ω、四位码 1002=10k(1%)。
读环方向：从靠近端头的一环读起；误差环（金/银）通常离得稍远。

  • 功率不够：12V 经 100Ω 到地，P=1.44W，1/8W 电阻会冒烟。

02 电容 Capacitor

一句话：电容存电荷、通交流隔直流，是电源干净与否的关键。

1. 四种典型用法

用法原理典型值
去耦/旁路给芯片瞬态电流「就近供血」，滤高频噪声100nF 每个电源脚 + 10µF 每板
滤波与 R 或 L 组成低通，平滑电压10µF~1000µF
耦合/隔直只让交流信号通过，挡住直流偏置1µF~10µF
储能/定时充放电产生延时；RC 决定 555 频率视需求

2. 关键参数

  • 容量：pF / nF / µF / F。1µF = 1000nF = 1,000,000pF。
  • 耐压：工作电压 ≤ 耐压的 70%（钽电容 ≤50%）。
  • ESR：等效串联电阻，越小高频性能越好（陶瓷 < 钽 < 电解）。
  • 极性：电解/钽有极性，反接会鼓包甚至爆浆。
  • 介质：X7R 稳定、Y5V 容量随电压/温度大跌（标 10µF 实际可能只有 4µF）。

3. 充放电与时间常数

τ = R × C；1τ 充到 63.2%，3τ 到 95%，5τ 视为充满。 应用：上电复位延时、按键去抖、LED 渐亮渐灭、555 定时。

4. 去耦的正确姿势

  • 100nF 陶瓷紧贴芯片电源脚放置（先经过电容再到芯片）。
  • 大电解/大钽放在电源入口滤低频。
  • 电容的接地端要走短而粗的路径回地。
  • ESP32 这类射频芯片，电源脚还要按模组手册加 π 型滤波。

5. 选型速查

场景推荐
芯片电源脚去耦100nF X7R 0603/0805
板级储能10~22µF 陶瓷 或 47~100µF 电解
5V 电源入口100µF/16V 电解 + 100nF
音频耦合1~10µF 薄膜/陶瓷
555 定时10nF~100µF 视频率
RTC 断电保持超级电容 0.1~1F

6. 常见坑

  • 电解极性接反：条纹侧是负；钽电容色条侧是正（与电解相反！）。
  • Y5V 当 X7R 用：标称容量在 3.3V 下严重缩水。
  • 去耦电容离芯片太远：电感效应让它失效。
  • 陶瓷电容的啸叫：电源纹波大时 MLCC 会压电发声，属正常物理现象。
  • 用容量档测好坏：容量正常但 ESR 变大的电解仍会引发复位/掉线，需 ESR 表或替换法。

7. 动手验证

  • 10kΩ + 100µF 接 3.3V，用万用表电压档观察充电曲线，估算 τ 是否≈1s。
  • 给 ESP32 的 3V3 与 GND 之间临时并/不并 100µF，观察 WiFi 发射时是否更稳定（串口看有无 brownout 复位）。

03 电感、磁珠与变压器

一句话：电感「抗拒电流变化」，把电能存在磁场里；磁珠是高频电阻；变压器用磁耦合传能量。

1. 电感基础

  • 单位 H / mH / µH；U = L × dI/dt：电流突变时产生反向电压。
  • 关键参数：感值、饱和电流 Isat（超过后感值骤降）、直流电阻 DCR、自谐振频率 SRF。
  • 典型用法：
  • DC-DC 储能：Buck/Boost 里的功率电感（4.7~22µH，Isat > 峰值电流）。
  • 扼流/滤波：与电容组成 LC 滤波，滤开关噪声。
  • 续流回路：继电器/电机线圈关断时，电流经续流二极管泄放（见 三极管开关）。

2. 磁珠 Ferrite Bead

  • 符号常画成「穿在导线上的矩形」。
  • 本质：高频损耗电阻。低频近似导线，高频变成电阻把噪声变成热。
  • 标称如 600Ω@100MHz：指 100MHz 时的阻抗。
  • 用法：串在电源入口或射频/数字边界，配合电容组成 π 型滤波。
  • 注意：磁珠有额定电流，过流会饱和失效；不要用它代替功率电感。

3. 变压器与共模电感

  • 变压器：匝数比决定电压比，提供电气隔离（开关电源、隔离串口模块）。
  • 共模电感：两绕组同向绕制，对共模噪声呈高阻，对差模信号无碍；用于电源入口抗干扰、CAN/USB 接口。

4. 选型速查

场景推荐
Buck 3.3V/1A4.7~10µH，Isat ≥2A，DCR <50mΩ
电源入口抗 EMI磁珠 600Ω@100MHz + 100nF + 10µF
继电器线圈续流不是电感！用 1N4148/SS34 二极管
射频匹配按模组手册的 π 型网络留位

5. 常见坑

  • 电感饱和：Isat 不够 → 电流尖峰、芯片发烫、效率骤降。
  • 把磁珠当电感储能：磁珠没有储能能力。
  • 布局比选型更重要：功率电感到开关管的环路要小，否则辐射超标。
  • 空心线圈靠近金属：感值漂移。

6. 动手验证

用万用表电阻档量电感：直流电阻很小（几 mΩ~几 Ω），若为 ∞ 则断线。 感值与 Isat 需要 LCR 表/厂家曲线，入门阶段以「按参考设计选」为主。

04 二极管与 LED

一句话：二极管只让电流单方向通过；LED 是会发光的二极管，但必须限流。

实物长什么样？见 00-元器件实物图鉴。

1. 核心特性

  • 正向导通压降 Vf：硅 0.6~0.7V，肖特基 0.2~0.4V，LED 1.8~3.3V。
  • 反向截止：只有 µA 级漏流；超过反向击穿电压 VBR 会损坏（稳压管例外，它工作在反向击穿区）。
  • 单向性记忆：符号箭头方向 = 允许电流方向；横杠 = 阴极（负极，色环/缺口标记）。

05 三极管 BJT 与 MOS 管

一句话：它们是「用小信号控制大电流」的电子开关；三极管靠电流驱动，MOS 靠电压驱动。

实物长什么样？见 00-元器件实物图鉴。

1. 三极管 BJT（NPN / PNP）

三个区：B 基极、C 集电极、E 发射极。Ic = β × Ib（β 约 100~300）。

两种工作状态：

状态条件用途
放大Vbe≈0.7V，Vce 居中音频放大、信号调理
饱和开关Ib 足够大，Vce≈0.2V驱动继电器/LED/电机

NPN 低边开关（最常用）：发射极接地，负载接在集电极与电源之间。

  • GPIO 高 → 导通；GPIO 低 → 关断。
  • 基极电阻 Rb = (Vgpio − 0.7) / (Ic/10)。

PNP 高边开关：发射极接电源，负载在集电极与地之间；GPIO 低导通（注意 GPIO 耐压要 ≥ 电源电压，否则用 MOS 或加电平转换）。

2. MOS 管（NMOS / PMOS）

三个极：G 栅、D 漏、S 源。电压驱动：栅极几乎不取电流。

参数含义新手要点
Vgs(th)开启阈值逻辑电平选 <1.5V 的型号
Rds(on)导通电阻越小发热越小（mΩ 级）
Id / 脉冲电流持续/瞬时电流留 2 倍余量
Vgs 耐压栅源极限通常 ±8~±20V，超压即坏

4. 常用型号

  • NPN：S8050、S9013、MMBT2222；达林顿 TIP122
  • PNP：S8550、S9012
  • NMOS：AO3400、SI2302、2N7002

5. 常见坑

  • 栅极悬空：MOS 栅极高阻，悬空会误导通甚至振荡烧毁 → 加 10k 下拉/上拉。
  • 把负载接在发射极：变成射极跟随器，压降大、难饱和。
  • 忘记续流二极管：感性负载反峰击穿管子。
  • Vgs 超压：12V 直接推栅极可能超过 ±20V？不会，但 5V 逻辑推「非逻辑电平」MOS 会导通不全发烫。
  • 并联使用不匹配：MOS 并联需均流设计，入门避免。

06 其他常用元器件速览

1. 晶振与时钟

  • 无源晶振（2 脚）+ 2 个 12~22pF 负载电容；有源晶振（4 脚）直接供电输出。
  • ESP32 模组内部已带 40MHz 晶振，自己画板用模组就不用管。
  • 32.768kHz 晶振用于 RTC 低功耗计时（ESP32 可用 GPIO32/33 外接）。

2. 继电器 Relay

  • 小电流控制大电流、强弱电隔离；线圈是感性负载 → 必须续流二极管。
  • 参数：线圈电压（3/5/12V）、触点容量（10A/250VAC 等）、吸合/释放时间（ms 级）。
  • 驱动：三极管/MOS + 续流二极管；或买带光耦隔离的模块。
  • 寿命：机械触点 10 万次级；高频开关选 MOS/固态继电器。

3. 光耦 Optocoupler

  • 输入发光二极管 + 输出光敏三极管，电气隔离（如 PC817）。
  • 用途：隔离串口、隔离开关量输入、隔离驱动继电器/可控硅。
  • 设计：输入串限流电阻（If≈5~10mA），输出加上拉电阻。

4. 运算放大器 Op-Amp

  • 三大基本电路：同相放大 G=1+Rf/Rg、反相放大 G=−Rf/Rin、电压跟随 G=1。
  • 用途：放大微弱传感器信号、做比较器、做有源滤波、做电压基准缓冲。
  • 单电源供电注意：输入/输出摆幅到不到轨（选 RRIO 型号）。

5. 555 定时器

  • 无稳态（闪烁/方波）、单稳态（延时/脉冲整形）、施密特（整形）。
  • 现代项目里多数功能已被单片机取代，但作为「无芯片也能 blink」的教学电路价值极高。

01 电压、电流、电阻与欧姆定律

一句话：电压是「推」，电流是「流」，电阻是「拦」；三者关系 U = I × R。

1. 水流类比

电学水路单位
电压 U水压/水位差伏特 V
电流 I水流量安培 A（mA=千分之一）
电阻 R管道粗细/阀门欧姆 Ω
功率 P水流做的功瓦特 W
  • 电压是两点之间的电位差，永远说「A 点相对 B 点几伏」。
  • 电流是电荷的流动，串联路径上处处相等。
  • 地 GND 是我们人为规定的 0V 参考点，不是「电的终点」。

2. 欧姆定律与功率

U = I × R      I = U / R      R = U / I
P = U × I = I² × R = U² / R

例题：3.3V 电源经 330Ω 电阻点亮红 LED（Vf=2.0V）。

  • 电阻两端电压 = 3.3 − 2.0 = 1.3V
  • 电流 I = 1.3 / 330 ≈ 3.9mA
  • 电阻功耗 P = 1.3 × 0.0039 ≈ 5mW（1/16W 足够）

3. 数量级直觉

量级例子
1µAESP32 深度睡眠、漏电
1mA指示 LED、上拉电阻电流
20mAGPIO 单脚上限（建议 ≤12mA）、亮 LED
100mA继电器线圈、ESP32 平均工作
300~500mAESP32 WiFi 发射峰值、舵机堵转
1~5A电机、灯带满亮

4. 测量三件套

  • 电压：并联，带电测。
  • 电流：串联进回路（或测采样电阻压降换算）。
  • 电阻/通断：断电测。

5. 常见误区

  • 「电流从正极流出被用掉」→ 电流在回路中守恒，被「用掉」的是能量。
  • 「GND 就是 0V 绝对值」→ 只是参考点；两个系统不共地，信号就没有回路。
  • 「电压高就危险」→ 危险取决于能否驱动足够电流通过人体；但高压更易击穿绝缘。
  • 忽略导线/接触电阻：大电流下 0.1Ω 接触电阻也会产生压降与发热。

6. 动手验证

  • 3.3V + 1kΩ + LED：分别测电阻压降、LED 压降，验证两者之和≈3.3V（基尔霍夫电压定律的雏形）。
  • 换 330Ω/1kΩ/10kΩ，观察亮度与实测电流，体会 I=U/R。

02 串并联、基尔霍夫定律、分压与分流

一句话：串联分压、并联分流；节点电流守恒（KCL）、回路电压守恒（KVL）。

1. 串联与并联

串联并联
电流处处相等按电导分配
电压按阻值分配处处相等
总阻值R1+R2+…1/(1/R1+1/R2+…)
直觉水管变长水管变粗

速算：两只相同电阻并联 = 一半；10k∥10k=5k；1k∥10k≈909Ω（接近小的那个）。

2. 基尔霍夫定律

  • KCL：流入节点的电流之和 = 流出之和。
  • KVL：沿任一闭合回路，电压升 = 电压降。

例题：节点 A 接 3.3V 经 10k，接 GND 经 10k，接 ADC（不取电流）。 KVL：3.3 = I×10k + I×10k → I=0.165mA → V_A = 1.65V。

3. 分压电路（ADC 采样必备）

Vout = Vin × R2 / (R1+R2)

设计步骤：

  • 确定被测最大值 Vin_max 与 ADC 量程（ESP32 建议 ≤3.1V）。
  • 选比例：R2/(R1+R2) = 3.1/Vin_max。
  • 选绝对值：总阻 10k~100k（太小耗电、太大受 ADC 采样电容影响）。
  • 并 100nF 电容稳定采样、滤噪声。

负载效应：若 Vout 接了会取电流的负载，负载与 R2 并联，分压比失真 → 后级加电压跟随器（运放）。

4. 分流电路

电流表扩程、LED 恒流近似、采样电阻都是分流/串采样思想。 I1 = Itotal × R2/(R1+R2)（两支路并联时）。

5. 常见坑

  • 分压电阻精度决定测量精度：用 ±1% 或 ±0.1%。
  • 忘记 ADC 输入阻抗限制：源阻抗 >100k 时读数偏低且漂移。
  • 并联电容过大：信号变化慢（RC 变大），测快速变化量会滞后。
  • 用分压给大电流负载供电：效率极低且不稳，请用稳压器。

6. 动手验证

  • 搭 10k+10k 分压接 3.3V，实测中点电压≈1.65V。
  • 在中点再接一只 10k 到地，重测（应≈1.1V），体会负载效应。
  • 用工具箱.html 的分压计算器反推电阻组合。

03 RC 电路与滤波

一句话：R 与 C 组合产生「时间」与「频率选择」，是模拟电路的第一课。

1. 时间常数 τ = RC

  • 充电：Uc = Vin × (1 − e^(−t/RC))；放电：Uc = Vin × e^(−t/RC)
  • 1τ=63.2%，3τ=95%，5τ=99.3%。
应用设计思路
上电复位延时RC 让 EN/RESET 脚缓慢升高，避开电源爬升
按键去抖10k+100nF（τ=1ms）吸收抖动毛刺
软启动/渐亮大 RC 驱动三极管基极
555 定时RA/RB/C 决定频率

2. 一阶低通 / 高通

fc = 1 / (2πRC)

  • 低通（R 串、C 并地）：低于 fc 通过；滤高频噪声、把 PWM 变模拟电压。
  • 高通（C 串、R 并地）：隔直流、传交流（音频耦合）。
  • 一阶滚降 6dB/倍频程；要更陡用二阶（两级 RC 或运放有源滤波）。

例题：ESP32 LEDC 输出 5kHz PWM，想变成平滑模拟电压： 取 fc ≈ 50Hz → R=10k 时 C = 1/(2π×10k×50) ≈ 318nF → 用 330nF。

3. 去耦也是滤波

电源入口：大电容滤低频 + 小陶瓷滤高频；芯片脚：100nF 就近。 本质都是「给噪声一条低阻抗的回地路径」。

4. 常见坑

  • 用 Y5V 电容做定时/滤波：容量随电压漂移，fc 不准。
  • 两级 RC 直接 cascaded 会互相加载：第二级输入阻抗要 ≥10× 第一级输出阻抗。
  • 滤得太狠：信号带宽不足，波形失真/响应慢。
  • 忽略源阻抗：信号源内阻会叠加进 R，改变 fc。

5. 动手验证

  • 10k+100nF 低通，输入 5kHz 方波（ESP32 PWM），示波器/逻辑分析仪看输出三角波幅度；改 50Hz 看是否变平。
  • 10k+10µF 接按键到地，观察复位/输入脚波形是否干净。

04 电源与供电：LDO、DC-DC 与电池

一句话：电源是电路的心脏；选错电源，后面一切调试都是徒劳。

1. 三类稳压方案

方案原理效率纹波典型芯片适用
LDO线性放大，压差变热(Vout/Vin)极低AMS1117-3.3、ME6217、HT7533压差小、电流小、射频前端
Buck 降压开关+电感储能85~95%中（mV 级）MP1584、TPS5430、SY8089压差大、电流大
Boost 升压开关升压85~95%中MT3608、SX1308电池升 5V/12V

LDO 发热：P = (Vin−Vout)×I。5V→3.3V @300mA = 0.51W，SOT-23 封装会烫；12V→3.3V @300mA = 2.6W，必须换 Buck。

2. ESP32 供电要点

  • 模组要求 3.3V ±0.3V，发射瞬间峰值电流 >300mA。
  • 开发板：USB 5V → 板载 LDO → 3.3V；用 5V/2A 以上 的 USB 电源或电脑口（部分电脑口仅 500mA 会 brownout 复位）。
  • 自己画板：LDO 选 ≥500mA 低压差（ME6217/RT9013），输入输出各 10~22µF + 100nF。
  • 电池方案：锂电 3.7V → LDO（压差够）或 Buck-Boost；加 TP4056 充电 + DW01 保护。

3. 电源树设计法

从负载往回推：

负载清单 → 各路电压/电流 → 选拓扑 → 算效率与发热 → 选器件 → 加保护(反接/过流/TVS)

例：ESP32(3.3V/240mA峰) + 传感器(3.3V/5mA) + 继电器(5V/70mA) + 灯带(5V/300mA) → 5V 主轨 Buck(12V→5V/1A)；3.3V 由 5V 经 LDO(500mA)；继电器/灯带直接 5V。

4. 电池与续航

  • 锂电 3.7V 标称：满 4.2V、空 3.0~3.3V；必须带保护板。
  • 容量 mAh × 3.7V / 1000 = Wh；续航 ≈ 容量 / 平均电流。
  • 降低平均电流的三板斧：深度睡眠、降低发射功率/占空比、关掉常耗电外设（分压电阻、上拉、LED）。

5. 常见坑

  • USB 口供电不足 → WiFi 一连就复位（brownout）。
  • LDO 压差不够：AMS1117 压差约 1.1~1.3V，3.7V 锂电放到 3.5V 时输出不足 3.3V → 选低压差 LDO。
  • 开关噪声进 ADC/射频：Buck 输出加 LC/磁珠滤波，布局环路要小。
  • 共地不良：多电源系统所有 GND 必须连在一起。
  • 热插拔浪涌：长导线+大电容上电瞬间电流冲击 → 加限流/预充或 TVS。

6. 动手验证

  • 测开发板 3V3 在 WiFi 扫描时的最低电压（万用表 min 档或示波器），应 >3.0V。
  • 摸 AMS1117 温度，体会 P=(Vin−Vout)×I。

05 数字信号、逻辑电平、ADC 与 PWM

一句话：数字世界只有高低电平；ADC 把模拟变数字，PWM 把数字变「伪模拟」。

1. 逻辑电平

家族高电平低电平注意
3.3V CMOS (ESP32)≥2.6V 认高，≤0.8V 认低输入耐压 ~3.6V
5V TTL/CMOS≥2.0V 认高≤0.8V5V 输出进 3.3V 脚需分压
开漏/开集需外部上拉I2C 就是开漏
  • 上拉/下拉：给引脚确定默认态；按键常用 10k 上拉 + 按下接地。
  • 悬空引脚：高阻态会乱跳、还可能增加功耗 → 一定要拉。
  • ESP32 内部上下拉约 45k，多数场景够用；总线/长线建议外部 4.7~10k。

2. ADC 模数转换

  • ESP32：12 位（0~4095），衰减档决定量程；ADC1 可与 WiFi 共存，ADC2 不行。
  • 误差来源：非线性（低端/高端差）、噪声、源阻抗、电源纹波。
  • 提精度四招：
  • 多次采样取中位数/平均（16~64 次）。
  • 输入并 100nF、串 1k 或更低源阻抗。
  • 用 3.3V 稳定电源做基准（或外部基准）。
  • 校准：两点校准（0V 与已知电压）存 NVS。

电压 = 读数/4095 × 量程；测高于量程的电压先分压。

3. DAC 与 PWM

  • ESP32 真 DAC：GPIO25/26，8 位，适合音频/简单波形。
  • PWM（LEDC）：改变占空比；配 RC 低通可得到平滑模拟电压；驱动 LED 亮度、舵机、电机速度。
  • LED：1~5kHz，占空比 0~100%。
  • 舵机：50Hz，脉宽 0.5~2.5ms。
  • 电机：10~20kHz 避开可听噪声。

4. 中断与定时

  • 边沿触发中断：按键、脉冲计数（编码器/流量计）。
  • 硬件定时器/PCNT：不占 CPU 的精确计数。
  • 消抖：硬件 RC 或软件 20ms 延时/状态机。

5. 常见坑

  • 5V 信号直进 GPIO → 损坏；用分压/电平转换/光耦。
  • ADC2 与 WiFi 同时用 → 读数全 0 或乱跳。
  • PWM 频率太低 LED 闪烁、电机啸叫；太高开关损耗大。
  • 开漏总线忘上拉 → 永远读低/读不到 ACK。
  • 用 delay() 做精确时序 → 被 WiFi/中断打断；用 hardware timer 或 micros()。

6. 动手验证

  • 电位器中点接 GPIO34，串口打印 ADC 值与换算电压；转动观察。
  • LEDC 1kHz 输出 0/25/50/75/100% 占空比，观察亮度；加 10k+10µF 低通后测平均电压是否≈占空比×3.3V。

  • 速率从低往高试；线长 >20cm 建议降速或加串阻。

01 如何读懂一张原理图

一句话：原理图是「电气连接」的地图，不是「物理位置」的照片；先找电源与地，再顺信号流读。

02 十个必会小电路（含计算与接线）

每个电路给出：原理图、关键计算、面包板要点、常见故障。全部可在面包板完成。

① LED 限流

  • R = (Vcc−Vf)/If；3.3V 红 LED 5mA → 270~330Ω。
  • 故障：不亮=极性/断线；微亮=电阻过大或 GPIO 电流不足。

② 按键 + 上拉（输入）

  • GPIO —(内部上拉 45k 或外部 10k)— 3V3；按键另一端接地。
  • 按下读 0，松开读 1；加 100nF 到地消抖。
  • 故障：读数乱跳=没上拉/没消抖/杜邦线松。

③ 分压采样（ADC 输入）

  • 测 12V：30k+10k → 3.0V 满量程；并 100nF。
  • 故障：读数偏低=源阻抗太大或没并电容。

④ NPN 三极管开关（驱动继电器/大 LED）

  • Rb=(3.3−0.7)/(Ic/10)；继电器 70mA → 330Ω。
  • 续流二极管阴极接电源正。
  • 故障：三极管烫=没饱和(Rb 太大)；继电器不吸=Ic 超管能力。

⑤ NMOS 低边开关（电机/灯带）

  • 栅极串 100Ω、下拉 10k；选逻辑电平 AO3400。
  • 故障：电机常转=栅极悬空/下拉缺失。

⑥ RC 低通（PWM 转模拟）

  • fc=1/(2πRC)；5kHz PWM → 10k+330nF（fc≈48Hz）。
  • 故障：输出有纹波=fc 太高；响应慢=fc 太低。

⑦ 555 闪烁（无 MCU 也能 blink）

  • f=1.44/((RA+2RB)C)；RA=1k、RB=10k、C=10µF → ≈6.8Hz。
  • 故障：不震荡=RA 接错/CTRL 脚悬空受扰（加 10nF）。

⑧ 运放同相放大（传感器信号调理）

  • G=1+Rf/Rg；10 倍：Rf=90k(用 100k 电位器调)、Rg=10k。
  • 单电源注意输入共模范围；加 100nF 电源去耦。
  • 故障：输出顶到电源轨=增益过大/偏置不对。

⑨ H 桥电机正反转

  • 入门直接用 TB6612/MX1508 模块；理解真值表与直通禁忌。
  • 故障：芯片烫=直通/过流；电机不转=使能脚没拉高。

⑩ LDO 电源（5V→3.3V）

  • AMS1117-3.3：输入 10µF、输出 22µF；注意压差与发热。
  • 故障：输出不稳=电容不足/输入压差不足/过载。

练习顺序建议

①→②→③ 一天；④→⑤ 一天；⑥→⑦ 一天；⑧→⑨→⑩ 两天。 每完成一个：拍照、记录实测值与计算值、写一句「我学到的」。

03 用 KiCad 画第一张原理图与 PCB

一句话：把面包板上的电路「固化」成板子：原理图 → 网络表 → 布局 → 布线 → 打样。

1. 工具与流程

  • KiCad（免费开源，中文界面）：原理图 Eeschema + PCB Pcbnew + 3D 预览。
  • 流程：建工程 → 画原理图(含 ERC) → 关联封装 → 导入 PCB → 布局 → 布线(DRC) → 出 Gerber → 打样 → 焊接 → 测试。

2. 原理图规范（让未来的你看得懂）

  • 电源符号统一：VCC/3V3/5V/GND 用标准符号，不要拉线满天飞。
  • 按功能分块摆放，信号左进右出。
  • 每个 IC 电源脚放 100nF 去耦，画在原理图上。
  • 关键网络命名：SDA/SCL/MOSI… 便于检查。
  • 跑 ERC：未连接引脚、单端网络、电源冲突都要处理。

3. 封装与器件库

  • 优先用厂家提供的封装/3D 模型（立创商城/LCSC 编号可直接搜）。
  • 电阻电容 0805 手焊友好；IC 选 SOP/SOIC 而非 QFN 入门。
  • 建 BOM：位号、型号、封装、LCSC/贸泽编号、数量。

4. PCB 布局布线入门规则

项目规则
板厚/层数入门 2 层 1.6mm
电源走线≥0.5mm(20mil)，大电流加宽或铺铜
信号走线0.2~0.25mm 足够
去耦电容紧贴 IC 电源脚，先电容后 IC
地2 层板底层尽量完整铺地
晶振/天线下方不走的信号、包地、远离接口
过孔电源过孔多打几个；信号 0.3mm 孔
丝印位号、极性、接口名称、版本号

5. 打样与焊接

  • 出 Gerber + 钻孔 + 拾取文件 → 打样厂（5 片约 ¥10~30）。
  • 贴片可选 SMT 贴片服务；手焊准备焊台、锡膏/锡丝、镊子、放大镜。
  • 回板检查：通断（电源对地不短路）→ 上电（限流电源或串电阻）→ 测各路电压 → 烧录测试。

6. 第一个板子建议做什么

「ESP32 最小系统 + OLED + DHT22 + 一个按键 + 一个 LED」传感器节点：

  • 用模组（WROOM-32）而非裸芯片，省射频与认证。
  • 留出所有未用 GPIO 的排针，方便后续玩。
  • 加电池座 + TP4056 充电，直接变成可穿戴原型。

7. 常见新手错误

  • 封装画错（引脚顺序/间距）→ 打样前用 3D 预览 + datasheet 核对。
  • 电源与地网络没连全 → DRC 报 unconnected。
  • 去耦电容画了但布局离 IC 远 → 等于没画。
  • 丝印被焊盘/元件压住 → 装配看不清。
  • 没留测试点 → 调试抓瞎。

02 引脚图与安全使用

一句话：ESP32 的 39 个 GPIO 里，有 6 个被 Flash 占用、4 个只能输入、5 个是上电配置脚——用错就「玄学故障」。

1. 引脚分类速记

类别引脚规则
Flash 占用GPIO6~11绝对不要用
仅输入GPIO34、35、36、39不能输出、无内部上拉，适合 ADC/唤醒
StrappingGPIO0、2、12、15上电瞬间电平决定启动模式/Flash 电压
串口0GPIO1(TX)、3(RX)烧录与日志占用，做普通 IO 会丢日志
PSRAMGPIO16、17仅 WROVER 模组占用
DACGPIO25、26真模拟输出
推荐「万能脚」4、5、13、14、16*、17*、18、19、21、22、23、25、26、27、32、33无特殊限制（*非 WROVER）

2. Strapping 引脚详解

  • GPIO0：上电低=下载模式；开发板有 10k 上拉+BOOT 键。
  • GPIO2：上电需低或悬空；板载 LED 常接这里（启动时闪一下属正常）。
  • GPIO12：上电必须为低（否则 Flash 电压切到 1.8V 启动失败）；做输出时注意上电瞬间是输入态。
  • GPIO15：上电高=默认日志波特率；拉低会静音启动日志。

3. 电气安全红线

  • GPIO 耐压 ≈3.6V：5V 信号必须分压/电平转换/光耦。
  • 单脚输出电流建议 ≤12mA（绝对 40mA）；总电流也有上限 → 驱动外部负载用三极管/MOS。
  • ADC2 与 WiFi 互斥：联网项目模拟采样只用 ADC1（GPIO32~39）。
  • ADC 非线性：低端/高端误差大，重要测量做两点校准或外部 ADC(ADS1115)。
  • 仅输入脚(34~39)没有内部上拉：做按键必须外部上拉。
  • 3V3 引脚对外供电能力取决于板载 LDO（常见 500~800mA），别接大负载。

4. 引脚分配建议模板

I2C   : SDA=21  SCL=22
SPI   : SCK=18  MISO=19  MOSI=23  CS=5
UART2 : RX=16   TX=17
ADC   : 34/35/36/39 (不联网也可 32/33)
PWM   : 25/26/27 (LEDC 任意)
按键  : 0 (BOOT 键可复用) / 4
LED   : 2 (板载)
WS2812: 4 或 8? → 用 4（8 是 Flash）
继电器: 26/27 (经三极管/MOS)

5. 动手验证

  • 跑 i2cscan、blink 确认板子正常。
  • 用万用表测 GPIO2 上电瞬间电平、GPIO0 静态电平（应≈3.3V）。
  • 故意把 GPIO12 接 3.3V 上电，观察启动失败现象，再改回——深刻记忆 strapping。

一句话：让 ESP32 可靠工作只需五部分：供电、复位、启动配置、烧录接口、天线。

部分关键器件参数要点

用两个三极管把 USB 串口的 DTR/RTS 组合成四种状态：

烧录工具按「复位→进下载→复位释放」的顺序自动完成，无需按键。

模组 (WROOM-32)裸芯片

4. PCB 布局要点（ESP32 专属）

  • 天线伸出板边或板边净空：天线下方与前方不铺铜、不放电池/金属。
  • 电源路径短而粗：LDO → 电容 → 模组 3V3 脚。
  • 晶振(若裸芯片)：包地、远离串口与开关信号。
  • 复位/启动脚走线短，避免被干扰误触发。
  • 大面积铺地提供射频回流路径。

  • [ ] 3V3 稳定、纹波 <50mV
  • [ ] EN 上电缓慢升到 3.3V（示波器/万用表 min-max）
  • [ ] GPIO0 上电为高
  • [ ] 串口 115200 有启动日志
  • [ ] WiFi 扫描成功、RSSI > −75dBm（近路由器）

07 低功耗设计：让电池活几个月

1. 功耗等级

模式典型电流保留唤醒
Active (WiFi TX)160~240mA 峰值全部—
Modem-sleep平均 ~20mACPU 运行、WiFi 连接保持自动
Light-sleep~0.8mACPU 暂停、RAM、WiFiGPIO/定时/UART
Deep-sleep~10µARTC 内存、RTC 外设定时/GPIO/触摸/ULP
Hibernation~2.5µA仅 RTC 慢速内存仅 RTC GPIO/定时

2. 电池项目标准架构

每 N 分钟唤醒 → 读传感器 → 上报(MQTT/BLE) → 立即 deep-sleep

平均电流 ≈ (唤醒时间 × 工作电流 + 睡眠时间 × 睡眠电流) / 周期

例：唤醒 1.5s @80mA + 睡眠 10µA，周期 300s： 平均 = (1.5×80 + 298.5×0.01)/300 ≈ 0.41mA → 1000mAh 电池 ≈ 100 天。

3. 降功耗 checklist

  • [ ] 用 deep-sleep 而非 delay()/light-sleep 长睡
  • [ ] 唤醒后先关不必要外设（OLED 灭、传感器断电脚）
  • [ ] 分压电阻加 MOS 开关，睡时断电（否则 10k+10k 常耗 0.16mA）
  • [ ] WiFi：固定信道/关 modem 休眠参数调优；或用 ESP-NOW/BLE 广播代替 WiFi
  • [ ] 降低 TX 功率 esp_wifi_set_max_tx_power
  • [ ] 选低压差 LDO 且 Iq 小（<10µA），或睡眠时关 LDO(使能脚)
  • [ ] 去掉板载 LED/USB 转串口的常耗电（量产板去掉 CH340 或加开关）
  • [ ] 电池自放电要计入：锂聚合物月自放 ~3~5%

4. 唤醒源代码骨架

// 定时 + 按键(GPIO0) 双唤醒
esp_sleep_enable_timer_wakeup(300ULL * 1000000);
esp_sleep_enable_ext0_wakeup((gpio_num_t)0, 0);  // 低电平唤醒

  • 专业：PPK2 / Joulescope / 万用表 µA 档串入（注意量程切换压降）。

02 面包板与杜邦线

1. 内部结构

  • 中间区：每 5 孔一列 横向导通（a-e 一组、f-j 一组），列与列之间绝缘。
  • 中间凹槽：IC 跨接，两侧不短路。
  • 上下电源轨：整条纵向导通（有的板中间断开，注意看丝印）。

2. 使用规范

  • 一列只插一根线或一个引脚。
  • 电源轨颜色习惯：红=+、黑=−。
  • IC 缺口朝上/朝左，便于数脚。
  • 大电流(>1A)、高频射频不走面包板。
  • 长期项目（>1 周）转洞洞板/打样板，面包板接触会劣化。

3. 杜邦线

  • 公-公、公-母、母-母各备一把；质量差的线时断时续。
  • 排查「玄学故障」第一步：换线或换一列。

03 焊接入门

1. 参数

项目建议
温度有铅 320°C / 无铅 350°C

锡丝0.5~0.8mm 含助焊剂芯

2. 五步法

  • 烙铁头同时接触焊盘与引脚预热 1s。
  • 送锡到焊点（不是烙铁头）。
  • 锡润湿铺开后撤锡丝。
  • 撤烙铁，静置 2s 不吹不动。
  • 剪脚留 1~2mm，洗板水清理。

3. 好焊点 vs 坏焊点

  • 好：光亮、凹面圆锥、润湿角小。
  • 坏：球状/灰暗/裂纹/拉尖 = 虚焊或冷焊 → 补焊。

4. 拆焊

  • 吸锡带：压住加热后提起。
  • 吸锡器：熔化后按键吸走。
  • 多脚 IC：堆锡拖焊 / 热风 350°C 小风量。
  • 贴片件：镊子+两头轮流加热。

5. 安全与习惯

  • 通风或排烟；焊完洗手（含铅锡）。
  • 烙铁归架、断电收纳；远离杜邦线与塑料。
  • 静电敏感器件(MOS/模组)：防静电手环或先摸地。
