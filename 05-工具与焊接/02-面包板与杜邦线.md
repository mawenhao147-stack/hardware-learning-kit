# 02 面包板与杜邦线

![面包板](../figures/breadboard-anatomy.png)

## 1. 内部结构

- 中间区：每 **5 孔一列** 横向导通（a-e 一组、f-j 一组），列与列之间绝缘。
- 中间凹槽：IC 跨接，两侧不短路。
- 上下电源轨：**整条纵向导通**（有的板中间断开，注意看丝印）。

## 2. 使用规范

1. 一列只插一根线或一个引脚。
2. 电源轨颜色习惯：红=+、黑=−。
3. IC 缺口朝上/朝左，便于数脚。
4. 大电流(>1A)、高频射频不走面包板。
5. 长期项目（>1 周）转洞洞板/打样板，面包板接触会劣化。

## 3. 杜邦线

- 公-公、公-母、母-母各备一把；质量差的线时断时续。
- 排查「玄学故障」第一步：换线或换一列。
- 长线(>30cm)传 I2C/SPI 易出错：降速或改短。

## 4. 从面包板到成品

面包板验证 → 洞洞板/万能板焊接 → KiCad 打样。
每一步都保留接线照片与 BOM，返工不慌。
