# 03 焊接入门

![焊接](../figures/soldering.png)

## 1. 参数

| 项目 | 建议 |
|---|---|
| 温度 | 有铅 320°C / 无铅 350°C |
| 单次加热 | ≤3 秒 |
| 锡丝 | 0.5~0.8mm 含助焊剂芯 |
| 烙铁头 | 刀头(K)通用、尖头(I)细脚 |

## 2. 五步法

1. 烙铁头同时接触焊盘与引脚预热 1s。
2. 送锡到**焊点**（不是烙铁头）。
3. 锡润湿铺开后撤锡丝。
4. 撤烙铁，静置 2s 不吹不动。
5. 剪脚留 1~2mm，洗板水清理。

## 3. 好焊点 vs 坏焊点

- 好：光亮、凹面圆锥、润湿角小。
- 坏：球状/灰暗/裂纹/拉尖 = 虚焊或冷焊 → 补焊。

## 4. 拆焊

- 吸锡带：压住加热后提起。
- 吸锡器：熔化后按键吸走。
- 多脚 IC：堆锡拖焊 / 热风 350°C 小风量。
- 贴片件：镊子+两头轮流加热。

## 5. 安全与习惯

- 通风或排烟；焊完洗手（含铅锡）。
- 烙铁归架、断电收纳；远离杜邦线与塑料。
- 静电敏感器件(MOS/模组)：防静电手环或先摸地。
