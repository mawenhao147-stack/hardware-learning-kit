# 04 调试方法与仪器

## 1. 调试四板斧

1. **看**：电源灯、LED、屏幕、串口日志。
2. **量**：电压→电流→通断→波形，由静到动。
3. **比**：与正常板/正常值对比。
4. **换**：模块、线、电源交叉验证。

## 2. 仪器进阶

| 仪器 | 能看到什么 | 入门价 |
|---|---|---|
| 逻辑分析仪 | 数字时序、协议解码(I2C/SPI/UART) | ¥60~150 |
| 示波器 50~100MHz | 模拟波形、纹波、边沿、振铃 | ¥300~1500 |
| 可调限流电源 | 安全上电、看整机电流变化 | ¥200~500 |
| ESR 表/LCR | 电容健康度、感值 | ¥100~400 |
| 热像仪 | 发热点定位 | ¥500+ |

## 3. 逻辑分析仪实战（I2C 不 ACK）

1. 夹 SDA/SCL/GND，采样 ≥8MHz。
2. 解码看地址与 ACK 位。
3. 无 ACK → 地址错/设备没上电/上拉缺失/SDA-SCL 接反。
4. 看边沿时间判断上拉是否过弱（边沿缓=上拉弱或电容大）。

## 4. 示波器实战（电源纹波）

- 探头 ×1、交流耦合、20MHz 限制、接地弹簧近测。
- 看峰峰值；ESP32 发射时的跌落(droop)比纹波更致命。
