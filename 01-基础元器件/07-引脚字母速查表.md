# 07 引脚字母速查表（离线版）

> 在线版支持按字母/中文搜索：打开首页 → 「引脚字母速查」。
> 记忆技巧：**先看类别再记含义**——电源类、总线类、器件类各有各的套路。

## 电源与地

| 丝印 | 全称 | 含义 |
|---|---|---|
| VCC | Voltage Common Collector | 正电源（BJT 工艺叫法，常见 5V/3.3V） |
| VDD / VSS | Drain / Source | 正电源 / 地（MOS 工艺叫法） |
| GND | Ground | 地，0V 参考点 |
| AGND / DGND | Analog / Digital GND | 模拟地 / 数字地（减少干扰） |
| VIN / VOUT | Voltage In / Out | 输入 / 输出电压 |
| VBAT | Battery | 电池电压 |
| B+ / B− | Battery ± | 电池正 / 负 |
| FB | Feedback | 稳压芯片反馈脚，决定输出电压 |
| SW | Switch node | DC-DC 开关节点，噪声大、走线要短 |
| PG / PGOOD | Power Good | 电源就绪指示输出 |

## 控制与通用

| 丝印 | 全称 | 含义 |
|---|---|---|
| EN / CE | Enable / Chip Enable | 使能：达到有效电平芯片才工作 |
| RST / NRST | Reset | 复位，通常低电平有效 |
| BOOT / IO0 | Boot mode | ESP32 上电拉低进入下载模式 |
| INT / IRQ | Interrupt | 中断输出，多为开漏需上拉 |
| PWM | Pulse Width Modulation | 脉宽调制（调光/调速/舵机） |
| ADC / DAC | A-D / D-A Converter | 模拟输入 / 模拟输出通道 |
| GPIO | General Purpose IO | 通用输入输出 |
| NC | No Connect | 空脚，不接 |

## 通信总线

| 丝印 | 全称 | 含义 |
|---|---|---|
| TX / RX | Transmit / Receive | 串口发 / 收（对接要交叉） |
| RTS / DTR | Request To Send / Data Terminal Ready | 流控线；ESP32 自动下载靠它们 |
| D+ / D− | USB differential | USB 差分数据 |
| CC | Configuration Channel | USB-C 方向与功率协商 |
| SDA / SCL | Serial Data / Clock | I2C 数据 / 时钟（开漏+上拉） |
| ADDR / A0 | Address | I2C 地址选择 |
| SCK / SCLK | Serial Clock | SPI 时钟 |
| MOSI / MISO | Master Out-In / In-Out | 主出从入 / 主入从出 |
| CS / SS / CSN | Chip Select | 片选，低有效 |
| DIN / DOUT | Data In / Out | 灯带、移位寄存器数据入 / 出 |
| DQ | Data Query | 1-Wire 单总线数据 |
| CANH / CANL | CAN High / Low | CAN 差分总线 |

## 器件引脚

| 丝印 | 全称 | 含义 |
|---|---|---|
| E / B / C | Emitter / Base / Collector | 三极管 发射 / 基 / 集电极 |
| G / D / S | Gate / Drain / Source | MOS 栅 / 漏 / 源极 |
| A / K | Anode / Cathode | 二极管、LED 阳 / 阴极 |
| IN+ / IN− | Non-inverting / Inverting | 运放同相 / 反相输入 |
| XTAL1/2 | Crystal | 晶振两脚 |
| COM / NO / NC | Common / Normally Open / Closed | 继电器 公共 / 常开 / 常闭 |

## 传感器与显示

| 丝印 | 全称 | 含义 |
|---|---|---|
| TRIG / ECHO | Trigger / Echo | 超声波 触发 / 回波 |
| XDA / XCL | Auxiliary I2C | MPU6050 辅助 I2C |
| DC / RS | Data / Command | 屏幕数据 / 命令选择 |
| BL / LED | Backlight | 屏幕背光 |
| T / NTC | Temperature | 电池温度检测脚 |

## 使用建议

1. 遇到不认识的丝印：先在本表搜；搜不到查 datasheet 的「Pin Description」表。
2. **同名不同义**警惕：NC 在继电器是常闭、在芯片是空脚；CS 在 SPI 是片选、在电流检测是 Current Sense。
3. 开漏输出（SDA/SCL/INT）必须上拉才能读高。
