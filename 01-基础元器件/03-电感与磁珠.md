# 03 电感、磁珠与变压器

**一句话**：电感「抗拒电流变化」，把电能存在磁场里；磁珠是高频电阻；变压器用磁耦合传能量。

![符号](../figures/symbols-passive.png)

## 1. 电感基础

- 单位 H / mH / µH；`U = L × dI/dt`：电流突变时产生反向电压。
- 关键参数：感值、**饱和电流 Isat**（超过后感值骤降）、直流电阻 DCR、自谐振频率 SRF。
- 典型用法：
  - **DC-DC 储能**：Buck/Boost 里的功率电感（4.7~22µH，Isat > 峰值电流）。
  - **扼流/滤波**：与电容组成 LC 滤波，滤开关噪声。
  - **续流回路**：继电器/电机线圈关断时，电流经续流二极管泄放（见 [三极管开关](../03-小型电路图实战/02-十个必会小电路.md)）。

## 2. 磁珠 Ferrite Bead

- 符号常画成「穿在导线上的矩形」。
- 本质：**高频损耗电阻**。低频近似导线，高频变成电阻把噪声变成热。
- 标称如 `600Ω@100MHz`：指 100MHz 时的阻抗。
- 用法：串在电源入口或射频/数字边界，配合电容组成 π 型滤波。
- 注意：磁珠有额定电流，过流会饱和失效；不要用它代替功率电感。

## 3. 变压器与共模电感

- 变压器：匝数比决定电压比，提供**电气隔离**（开关电源、隔离串口模块）。
- 共模电感：两绕组同向绕制，对共模噪声呈高阻，对差模信号无碍；用于电源入口抗干扰、CAN/USB 接口。

## 4. 选型速查

| 场景 | 推荐 |
|---|---|
| Buck 3.3V/1A | 4.7~10µH，Isat ≥2A，DCR <50mΩ |
| 电源入口抗 EMI | 磁珠 600Ω@100MHz + 100nF + 10µF |
| 继电器线圈续流 | 不是电感！用 1N4148/SS34 二极管 |
| 射频匹配 | 按模组手册的 π 型网络留位 |

## 5. 常见坑

1. **电感饱和**：Isat 不够 → 电流尖峰、芯片发烫、效率骤降。
2. **把磁珠当电感储能**：磁珠没有储能能力。
3. **布局比选型更重要**：功率电感到开关管的环路要小，否则辐射超标。
4. **空心线圈靠近金属**：感值漂移。

## 6. 动手验证

用万用表电阻档量电感：直流电阻很小（几 mΩ~几 Ω），若为 ∞ 则断线。
感值与 Isat 需要 LCR 表/厂家曲线，入门阶段以「按参考设计选」为主。
