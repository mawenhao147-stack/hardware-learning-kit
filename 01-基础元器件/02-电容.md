# 02 电容 Capacitor

**一句话**：电容存电荷、通交流隔直流，是电源干净与否的关键。

![类型](../figures/cap-types.png)

## 1. 四种典型用法

| 用法 | 原理 | 典型值 |
|---|---|---|
| 去耦/旁路 | 给芯片瞬态电流「就近供血」，滤高频噪声 | 100nF 每个电源脚 + 10µF 每板 |
| 滤波 | 与 R 或 L 组成低通，平滑电压 | 10µF~1000µF |
| 耦合/隔直 | 只让交流信号通过，挡住直流偏置 | 1µF~10µF |
| 储能/定时 | 充放电产生延时；RC 决定 555 频率 | 视需求 |

## 2. 关键参数

- **容量**：pF / nF / µF / F。1µF = 1000nF = 1,000,000pF。
- **耐压**：工作电压 ≤ 耐压的 70%（钽电容 ≤50%）。
- **ESR**：等效串联电阻，越小高频性能越好（陶瓷 < 钽 < 电解）。
- **极性**：电解/钽有极性，**反接会鼓包甚至爆浆**。
- **介质**：X7R 稳定、Y5V 容量随电压/温度大跌（标 10µF 实际可能只有 4µF）。

## 3. 充放电与时间常数

![RC](../figures/rc-charge-curve.png)

`τ = R × C`；1τ 充到 63.2%，3τ 到 95%，5τ 视为充满。
应用：上电复位延时、按键去抖、LED 渐亮渐灭、555 定时。

## 4. 去耦的正确姿势

1. 100nF 陶瓷**紧贴**芯片电源脚放置（先经过电容再到芯片）。
2. 大电解/大钽放在电源入口滤低频。
3. 电容的接地端要走短而粗的路径回地。
4. ESP32 这类射频芯片，电源脚还要按模组手册加 π 型滤波。

## 5. 选型速查

| 场景 | 推荐 |
|---|---|
| 芯片电源脚去耦 | 100nF X7R 0603/0805 |
| 板级储能 | 10~22µF 陶瓷 或 47~100µF 电解 |
| 5V 电源入口 | 100µF/16V 电解 + 100nF |
| 音频耦合 | 1~10µF 薄膜/陶瓷 |
| 555 定时 | 10nF~100µF 视频率 |
| RTC 断电保持 | 超级电容 0.1~1F |

## 6. 常见坑

1. **电解极性接反**：条纹侧是负；钽电容色条侧是**正**（与电解相反！）。
2. **Y5V 当 X7R 用**：标称容量在 3.3V 下严重缩水。
3. **去耦电容离芯片太远**：电感效应让它失效。
4. **陶瓷电容的啸叫**：电源纹波大时 MLCC 会压电发声，属正常物理现象。
5. **用容量档测好坏**：容量正常但 ESR 变大的电解仍会引发复位/掉线，需 ESR 表或替换法。

## 7. 动手验证

1. 10kΩ + 100µF 接 3.3V，用万用表电压档观察充电曲线，估算 τ 是否≈1s。
2. 给 ESP32 的 3V3 与 GND 之间临时并/不并 100µF，观察 WiFi 发射时是否更稳定（串口看有无 brownout 复位）。
