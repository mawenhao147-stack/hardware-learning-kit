# 05 三极管 BJT 与 MOS 管

**一句话**：它们是「用小信号控制大电流」的电子开关；三极管靠电流驱动，MOS 靠电压驱动。

![半导体符号](../figures/symbols-semi.png)

## 1. 三极管 BJT（NPN / PNP）

三个区：B 基极、C 集电极、E 发射极。`Ic = β × Ib`（β 约 100~300）。

**两种工作状态**：

| 状态 | 条件 | 用途 |
|---|---|---|
| 放大 | Vbe≈0.7V，Vce 居中 | 音频放大、信号调理 |
| 饱和开关 | Ib 足够大，Vce≈0.2V | 驱动继电器/LED/电机 |

**NPN 低边开关**（最常用）：发射极接地，负载接在集电极与电源之间。
- GPIO 高 → 导通；GPIO 低 → 关断。
- 基极电阻 Rb = (Vgpio − 0.7) / (Ic/10)。

![NPN开关](../figures/npn-switch.png)

**PNP 高边开关**：发射极接电源，负载在集电极与地之间；GPIO 低导通（注意 GPIO 耐压要 ≥ 电源电压，否则用 MOS 或加电平转换）。

## 2. MOS 管（NMOS / PMOS）

三个极：G 栅、D 漏、S 源。**电压驱动**：栅极几乎不取电流。

| 参数 | 含义 | 新手要点 |
|---|---|---|
| Vgs(th) | 开启阈值 | 逻辑电平选 <1.5V 的型号 |
| Rds(on) | 导通电阻 | 越小发热越小（mΩ 级） |
| Id / 脉冲电流 | 持续/瞬时电流 | 留 2 倍余量 |
| Vgs 耐压 | 栅源极限 | 通常 ±8~±20V，超压即坏 |

**用法**：NMOS 低边（源极接地）、PMOS 高边（源极接电源）。
3.3V GPIO 想控制 5~12V 的 PMOS，要加一级 NPN 做电平转换：

![MOS高低边](../figures/mos-switch.png)

## 3. BJT vs MOS 怎么选

| 维度 | BJT | MOS |
|---|---|---|
| 驱动 | 电流（持续耗电） | 电压（几乎不耗电） |
| 饱和压降 | 0.2V 固定 | I×Rds(on)，可极低 |
| 速度 | 较慢 | 快（注意栅极振铃） |
| 成本 | 极低 | 低 |
| 典型 | S8050 驱动小继电器 | AO3400 驱动电机/灯带 |

## 4. 常用型号

- NPN：S8050、S9013、MMBT2222；达林顿 TIP122
- PNP：S8550、S9012
- NMOS：AO3400、SI2302、2N7002
- PMOS：AO3401、SI2301

## 5. 常见坑

1. **栅极悬空**：MOS 栅极高阻，悬空会误导通甚至振荡烧毁 → 加 10k 下拉/上拉。
2. **把负载接在发射极**：变成射极跟随器，压降大、难饱和。
3. **忘记续流二极管**：感性负载反峰击穿管子。
4. **Vgs 超压**：12V 直接推栅极可能超过 ±20V？不会，但 5V 逻辑推「非逻辑电平」MOS 会导通不全发烫。
5. **并联使用不匹配**：MOS 并联需均流设计，入门避免。

## 6. 动手验证

1. NPN + 1k 基极电阻 + LED/330Ω 集电极负载：GPIO/电池切换高低，观察亮灭。
2. 换 AO3400 重复实验，用万用表测 D-S 压降对比 Vce。
3. 用继电器替换 LED，去掉/加上续流二极管各试一次（去掉时听「啪」的火花声并观察三极管是否发热——点到为止，别长时间）。
