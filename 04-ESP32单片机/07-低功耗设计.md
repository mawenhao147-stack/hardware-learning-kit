# 07 低功耗设计：让电池活几个月

![功耗](../figures/esp32-sleep-currents.png)

## 1. 功耗等级

| 模式 | 典型电流 | 保留 | 唤醒 |
|---|---|---|---|
| Active (WiFi TX) | 160~240mA 峰值 | 全部 | — |
| Modem-sleep | 平均 ~20mA | CPU 运行、WiFi 连接保持 | 自动 |
| Light-sleep | ~0.8mA | CPU 暂停、RAM、WiFi | GPIO/定时/UART |
| Deep-sleep | ~10µA | RTC 内存、RTC 外设 | 定时/GPIO/触摸/ULP |
| Hibernation | ~2.5µA | 仅 RTC 慢速内存 | 仅 RTC GPIO/定时 |

## 2. 电池项目标准架构

```
每 N 分钟唤醒 → 读传感器 → 上报(MQTT/BLE) → 立即 deep-sleep
```

平均电流 ≈ (唤醒时间 × 工作电流 + 睡眠时间 × 睡眠电流) / 周期

例：唤醒 1.5s @80mA + 睡眠 10µA，周期 300s：
平均 = (1.5×80 + 298.5×0.01)/300 ≈ 0.41mA → 1000mAh 电池 ≈ 100 天。

## 3. 降功耗 checklist

- [ ] 用 deep-sleep 而非 delay()/light-sleep 长睡
- [ ] 唤醒后先关不必要外设（OLED 灭、传感器断电脚）
- [ ] 分压电阻加 MOS 开关，睡时断电（否则 10k+10k 常耗 0.16mA）
- [ ] WiFi：固定信道/关 modem 休眠参数调优；或用 ESP-NOW/BLE 广播代替 WiFi
- [ ] 降低 TX 功率 `esp_wifi_set_max_tx_power`
- [ ] 选低压差 LDO 且 Iq 小（<10µA），或睡眠时关 LDO(使能脚)
- [ ] 去掉板载 LED/USB 转串口的常耗电（量产板去掉 CH340 或加开关）
- [ ] 电池自放电要计入：锂聚合物月自放 ~3~5%

## 4. 唤醒源代码骨架

```cpp
// 定时 + 按键(GPIO0) 双唤醒
esp_sleep_enable_timer_wakeup(300ULL * 1000000);
esp_sleep_enable_ext0_wakeup((gpio_num_t)0, 0);  // 低电平唤醒
esp_deep_sleep_start();
```

唤醒原因查询：`esp_sleep_get_wakeup_cause()`。

## 5. 测量工具

- 串口功率计/USB 电流表看平均（含唤醒脉冲需采样快的）。
- 专业：PPK2 / Joulescope / 万用表 µA 档串入（注意量程切换压降）。
- 没有工具时：用 1Ω 采样电阻 + 示波器看压降波形估算。
