# 04 开发环境搭建（Arduino / PlatformIO / ESP-IDF）

**一句话**：三条路线任选其一；入门推荐 Arduino IDE 或 PlatformIO，产品/进阶用 ESP-IDF。

## 1. 路线 A：Arduino IDE（最快上手）

1. 安装 Arduino IDE 2.x。
2. 偏好设置 → 附加开发板管理器网址：
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
3. 开发板管理器搜 **esp32** 安装（2026 年主流为 3.3.x，基于 ESP-IDF 5.5）。
4. 开发板选 `ESP32 Dev Module`（或对应型号）；参数：
   - Flash Size: 4MB；Partition: Default 4MB with spiffs
   - CPU Frequency: 240MHz；Upload Speed: 921600
5. 选对串口（macOS: `/dev/cu.usbserial-*`；Windows: COMx；CH340 需驱动）。
6. 示例 → Blink → 上传。看到板载 LED 闪烁即成功。

## 2. 路线 B：PlatformIO（工程化管理，推荐）

```ini
; platformio.ini
[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino
monitor_speed = 115200
upload_speed = 921600
lib_deps =
    adafruit/Adafruit SSD1306
    adafruit/DHT sensor library
```

- VS Code 装 PlatformIO 插件 → 新建工程 → 选 `Espressif ESP32 Dev Board`。
- 优点：依赖自动管理、多工程、串口监视、一键 OTA 配置。

## 3. 路线 C：ESP-IDF（官方全功能）

```bash
# 安装 esp-idf 5.5+（含工具链）
git clone -b v5.5 --recursive https://github.com/espressif/esp-idf.git
cd esp-idf && ./install.sh esp32 && . ./export.sh
idf.py create-project myapp && cd myapp && idf.py build flash monitor
```

- 菜单配置 `idf.py menuconfig`；组件管理 `idf.py add-dependency`。
- FreeRTOS 双核、功耗、射频参数全可控。

## 4. MicroPython（交互实验）

- 烧 MicroPython 固件后用 Thonny/REPL：`machine.Pin(2, Pin.OUT).value(1)` 即时点灯。
- 适合教学与快速验证，性能与生态弱于 C/C++。

## 5. 驱动与串口排错

| 现象 | 处理 |
|---|---|
| 找不到串口 | 装 CH340/CP2102 驱动；换 USB 线（很多线只能充电） |
| macOS 提示权限 | 用 `/dev/cu.*` 而非 `/dev/tty.*` |
| 上传卡 connecting | 按住 BOOT 再点上传；或检查自动下载电路 |
| 乱码 | 波特率改 115200；日志波特率受 GPIO15 影响 |

## 6. 第一个程序之后的练习清单

1. Blink → 改间隔 → 用 `millis()` 非阻塞改写。
2. 按键输入（内部上拉）+ 串口打印。
3. PWM 呼吸灯（LEDC）。
4. ADC 读电位器 → 映射到呼吸灯。
5. WiFi 扫描并打印 SSID/RSSI。
