# 02 引脚图与安全使用

**一句话**：ESP32 的 39 个 GPIO 里，有 6 个被 Flash 占用、4 个只能输入、5 个是上电配置脚——用错就「玄学故障」。

![引脚图](../figures/esp32-devkit-pinout.png)

## 1. 引脚分类速记

| 类别 | 引脚 | 规则 |
|---|---|---|
| Flash 占用 | GPIO6~11 | **绝对不要用** |
| 仅输入 | GPIO34、35、36、39 | 不能输出、无内部上拉，适合 ADC/唤醒 |
| Strapping | GPIO0、2、12、15 | 上电瞬间电平决定启动模式/Flash 电压 |
| 串口0 | GPIO1(TX)、3(RX) | 烧录与日志占用，做普通 IO 会丢日志 |
| PSRAM | GPIO16、17 | 仅 WROVER 模组占用 |
| DAC | GPIO25、26 | 真模拟输出 |
| 推荐「万能脚」 | 4、5、13、14、16*、17*、18、19、21、22、23、25、26、27、32、33 | 无特殊限制（*非 WROVER） |

![GPIO能力表](../figures/esp32-gpio-map.png)

## 2. Strapping 引脚详解

![启动](../figures/esp32-strapping.png)

- **GPIO0**：上电低=下载模式；开发板有 10k 上拉+BOOT 键。
- **GPIO2**：上电需低或悬空；板载 LED 常接这里（启动时闪一下属正常）。
- **GPIO12**：上电必须为低（否则 Flash 电压切到 1.8V 启动失败）；做输出时注意上电瞬间是输入态。
- **GPIO15**：上电高=默认日志波特率；拉低会静音启动日志。

## 3. 电气安全红线

1. **GPIO 耐压 ≈3.6V**：5V 信号必须分压/电平转换/光耦。
2. **单脚输出电流建议 ≤12mA**（绝对 40mA）；总电流也有上限 → 驱动外部负载用三极管/MOS。
3. **ADC2 与 WiFi 互斥**：联网项目模拟采样只用 ADC1（GPIO32~39）。
4. **ADC 非线性**：低端/高端误差大，重要测量做两点校准或外部 ADC(ADS1115)。
5. 仅输入脚(34~39)没有内部上拉：做按键必须外部上拉。
6. 3V3 引脚对外供电能力取决于板载 LDO（常见 500~800mA），别接大负载。

## 4. 引脚分配建议模板

```text
I2C   : SDA=21  SCL=22
SPI   : SCK=18  MISO=19  MOSI=23  CS=5
UART2 : RX=16   TX=17
ADC   : 34/35/36/39 (不联网也可 32/33)
PWM   : 25/26/27 (LEDC 任意)
按键  : 0 (BOOT 键可复用) / 4
LED   : 2 (板载)
WS2812: 4 或 8? → 用 4（8 是 Flash）
继电器: 26/27 (经三极管/MOS)
```

## 5. 动手验证

1. 跑 `i2cscan`、`blink` 确认板子正常。
2. 用万用表测 GPIO2 上电瞬间电平、GPIO0 静态电平（应≈3.3V）。
3. 故意把 GPIO12 接 3.3V 上电，观察启动失败现象，再改回——深刻记忆 strapping。
