# 03 最小系统与硬件设计

**一句话**：让 ESP32 可靠工作只需五部分：供电、复位、启动配置、烧录接口、天线。

![最小系统](../figures/esp32-min-system.png)

## 1. 五要素清单

| 部分 | 关键器件 | 参数要点 |
|---|---|---|
| 供电 | LDO ME6217/AMS1117-3.3 | ≥500mA、低压差；入/出 10~22µF + 100nF |
| 复位 EN | 10k 上拉 + 1µF + 按键 | RC 延时避开电源爬升 |
| 启动 GPIO0 | 10k 上拉 + 按键 | 上电高=运行，低=下载 |
| 烧录 | USB-UART(CH340/CP2102) + 自动下载电路 | DTR/RTS 控制 EN 与 GPIO0 |
| 天线 | 模组自带 PCB 天线 | 天线区禁铺铜、禁金属遮挡 |

## 2. 自动下载电路原理

用两个三极管把 USB 串口的 DTR/RTS 组合成四种状态：

| DTR | RTS | EN | GPIO0 | 结果 |
|---|---|---|---|---|
| 0 | 0 | 高 | 高 | 运行 |
| 0 | 1 | 低 | 高 | 复位 |
| 1 | 0 | 高 | 低 | 进下载 |
| 1 | 1 | 高 | 高 | 运行 |

烧录工具按「复位→进下载→复位释放」的顺序自动完成，无需按键。

## 3. 用模组还是裸芯片

| | 模组 (WROOM-32) | 裸芯片 |
|---|---|---|
| 射频调试 | 已完成 | 需网络分析仪 |
| 认证 | 模组有认证 | 整机需认证 |
| 外围 | 只需电源/复位/烧录 | 还要晶振/Flash/天线匹配 |
| 成本 | 高 ¥3~8 | 低 ¥1~2 |
| 建议 | **入门与中小批量** | 大批量且有能力做射频 |

## 4. PCB 布局要点（ESP32 专属）

1. 天线伸出板边或板边净空：天线下方与前方不铺铜、不放电池/金属。
2. 电源路径短而粗：LDO → 电容 → 模组 3V3 脚。
3. 晶振(若裸芯片)：包地、远离串口与开关信号。
4. 复位/启动脚走线短，避免被干扰误触发。
5. 大面积铺地提供射频回流路径。

## 5. 上电自检清单

- [ ] 3V3 稳定、纹波 <50mV
- [ ] EN 上电缓慢升到 3.3V（示波器/万用表 min-max）
- [ ] GPIO0 上电为高
- [ ] 串口 115200 有启动日志
- [ ] WiFi 扫描成功、RSSI > −75dBm（近路由器）
