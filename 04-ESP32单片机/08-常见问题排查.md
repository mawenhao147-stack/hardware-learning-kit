# 08 常见问题排查（故障树）

## A. 烧录/连接类

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 找不到串口 | 驱动/线/口选错 | 装 CH340/CP2102 驱动；换数据线；macOS 用 /dev/cu.* |
| 卡 `Connecting....` | 未进下载模式 | 按住 BOOT 再上传；检查自动下载电路 |
| 上传后无日志 | 波特率/串口被占 | 115200；关掉其他串口工具 |
| 反复复位 | 电源不足/brownout | 换 5V2A 电源；3V3 加 100~470µF |

## B. 运行类

| 现象 | 可能原因 | 处理 |
|---|---|---|
| WiFi 连不上 | 密码/2.4G/信道 | ESP32 只支持 2.4GHz；路由器开 2.4G 混合模式 |
| 连上就断 | 电源峰值不足 | 同上；或降低 TX 功率 |
| GPIO 无输出 | 用了 6~11/34~39 | 换脚 |
| 读数乱跳 | ADC 噪声/源阻抗 | 多次采样、并 100nF、降源阻抗 |
| ADC2 读 0 | 与 WiFi 互斥 | 换 ADC1 |
| I2C 找不到设备 | 地址/上拉/接线 | i2cscan；检查 4.7k 上拉；SDA/SCL 别接反 |
| 时好时坏 | 杜邦线/面包板接触 | 换线换列；焊接 |
| 发热烫手 | 短路/过载/LDO 压差大 | 断电摸查；串电流表看整机电流 |

## C. 启动类

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 上电无反应 | 电源/EN | 测 3V3；测 EN 是否≈3.3V |
| 启动日志乱码 | 波特率 | 115200 |
| 启动后停住 | GPIO12/15 被外部拉错 | 移除上电时的外部驱动 |
| 无限重启 | 看门狗/电源/代码 | 看复位原因 `rtc_get_reset_reason` |

## D. 调试方法论

1. **二分法**：注释一半代码，定位问题区间。
2. **最小复现**：只留出问题的那 10 行。
3. **看日志等级**：`esp_log_level_set("*", ESP_LOG_DEBUG)`。
4. **量三样**：电压、电流、波形——多数「软件问题」最后是硬件。
5. **换件交叉验证**：模块、线、板子轮流换。
6. 记录：每次故障写「现象-假设-验证-结论」四行。
